# poly-dry

A CLI tool to find duplicated code within a codebase, inspired by Uncle Bob's [dryer](https://github.com/unclebob/dryer) tool and a custom fork of Drew Simmons's [poly-crap](https://github.com/gianni-rg/poly-crap) tool (Rust implementation, architecture and multi-language support).

## Contribution

The project is constantly evolving and contributions are warmly welcomed.

I'm more than happy to receive any kind of contribution to this project: from helpful feedbacks to bug reports, documentation, usage examples, feature requests, or directly contributions for bug fixes and new and/or improved features.

Feel free to file issues on the repository and I'll try to address them as much as I can, *with a best effort approach during my spare time*. DO NOT expect a super fast turnaround, but I'll do my best to keep the project active and responsive.

> Given that development is mainly done on Windows/WSL, other platforms are not directly developed, tested, or supported. Help is kindly appreciated in making the tool work on other platforms as well.
